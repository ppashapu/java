/ - forward slash
\ - backward slash

git clone -> to clone the remote repository
git status -> to check the status/ or progress of the git
git add . -> to add the files to the staging staging stage here we can specify the files which we want with the file name
git commit -> to add files from staging stage to local repository but it adds all the files as batch from are in staging stage
git push -> to push the file/code to remote repository

Get latest changes:
git pull Check the current branch details:
git branch  --> execute this command to get the current branch 
git merge <branch_name> --> to merge the branch in to the current branch
git stash --> to save it temp
